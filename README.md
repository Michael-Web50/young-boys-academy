# Young Boys Football Academy 🏆

Official website for Young Boys Football Academy, located at Sanya Street, Surulere, Lagos.

## 🎯 Mission
Forging the next generation of champions through **Discipline, Hardwork, and Consistency**.

## ⚽ Age Groups
- Under 12 (U12)
- Under 15 (U15)
- Under 17 (U17)
- Under 20 (U20)

## 📅 Training Schedule
- **Tuesday**: Fitness & Conditioning
- **Thursday**: Technical & Tactical
- **Saturday**: Match Day / Scrimmage

## 🛠️ Tech Stack
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

## 🚀 Features
- Responsive design (mobile-first)
- Player profiles with image upload
- Coaching staff showcase
- News & announcements system
- Sponsorship application management
- Professional admin dashboard
- Brand colors: Yellow, Black, and White
